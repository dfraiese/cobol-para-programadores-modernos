# COBOL para programadores modernos

## Diego Fraiese

**Libro gratuito sobre COBOL, sistemas críticos y el modelo mental detrás del lenguaje.**

Este libro está dirigido especialmente a programadores formados con lenguajes y paradigmas modernos que quieren comprender por qué COBOL funciona de una manera tan diferente.

No es un manual exhaustivo de sintaxis.

El objetivo es explicar el modelo mental detrás de COBOL y de los sistemas críticos: datos, estado, procesamiento batch, control explícito del flujo, registros, precisión y riesgo operativo.

## Contenido

- Breve historia de COBOL
- El modelo mental de COBOL
- Estructura de un programa COBOL
- IDENTIFICATION DIVISION
- ENVIRONMENT DIVISION
- DATA DIVISION
- PROCEDURE DIVISION
- PERFORM y control de flujo
- Registros y estado
- Tipos numéricos y COMP-3
- Puntuación y código estructurado
- CALL y subprogramas
- Archivos secuenciales
- Control de errores en procesos batch
- Por qué COBOL sigue existiendo
